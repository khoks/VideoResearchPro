# Written from general knowledge BEFORE the labelled evaluation set was read,
# so the held-out score is not a score on words the list was fitted to.
# Words added afterwards from the DEV split are in the last section, marked.

# Spelling variants are listed separately because romanised Hindi has no
# standard orthography: nahi / nahin / nai / nhi are all common.

# Words that are ALSO common English (to, the, main, me, is, us, so, do, hi,
# par, man, log, band, pure, sake, lag, tab, mat, sun, hum, ...) may appear
# here; the service treats any word present in both this list and the English
# vocabulary as AMBIGUOUS and resolves it from context, so listing them is
# correct, not a false positive.
