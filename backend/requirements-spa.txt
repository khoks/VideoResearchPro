# Optional SPA-extraction dependencies for article-extraction Playwright fallback.
#
# Per E-1.6 T-1.6.6 / D-024, Playwright is **opt-in** because Chromium
# binaries weigh ~150MB and the JS-rendering path isn't needed for
# most articles (trafilatura's static-HTML path covers the common case).
# Operators who want SPA support — for ingesting paywalled-but-public
# content from JS-heavy news sites, or Mode B paste-mode for FB / IG
# (S-1.5.8 T-1.5.8.5) — install via:
#
#   pip install -r backend/requirements-spa.txt
#   playwright install chromium  # downloads the browser binary (~150MB)
#
# Then flip in `.env`:
#
#   ARTICLE_PLAYWRIGHT_ENABLED=True
#
# The default install (just `requirements.txt`) keeps Pratidhvani lean.
# If SPA support is unavailable at runtime, the fallback short-circuits
# with a clear INFO log — never raises, never crashes the orchestrator.

# Pull in the base requirements first so the SPA install is additive.
-r requirements.txt

playwright>=1.50.0
